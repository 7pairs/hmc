| ファイル | 内容 |
|---|---|

| [sora-and-umi.png](sora-and-umi.png) | そらとうみが並んだ完成画像 |

HASEBA Junya (7pairs)は、そら・うみと相談して外見や配色を決め、OpenAIの画像生成を使って完成画像を制作した。個別画像には完成画像の白い背景と水彩の質感を残している。

表紙画像は、HASEBA Junya (7pairs)がそら・うみと構図を相談し、二人の紹介画像と[Sora Flowの表紙画像](../../sora-flow/assets/sora-git-log.png)を参照して、OpenAIの画像生成で制作した。
